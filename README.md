# Frontend Store

Frontend Store es un proyecto de tienda online desarrollado como parte de mi formación en desarrollo web.

El proyecto presenta un catálogo de camisetas relacionadas con tecnologías de desarrollo, una sección informativa sobre la tienda y una página individual de producto.

## Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Metodología BEM
- Responsive Design

## Características

- Catálogo de productos.
- Página individual de producto.
- Selector de talla y cantidad.
- Sección "Nosotros".
- Diseño adaptable a diferentes tamaños de pantalla.
- Organización de estilos utilizando metodología BEM.
- Uso de CSS Grid y Flexbox para la distribución de los elementos.

## Aprendizajes

Durante este proyecto practiqué principalmente:

- Estructuración de páginas con HTML semántico.
- Metodología BEM para organizar las clases CSS.
- CSS Grid para crear y posicionar elementos.
- Flexbox.
- Media Queries.
- Diseño Mobile First.
- Formularios y campos de selección.
- Pseudoclases como `:hover`.
- Transiciones en CSS.
